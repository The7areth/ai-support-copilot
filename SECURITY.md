# Security scope

This prototype is for local synthetic-data demos. It has no authentication or rate limiting. Do not expose it publicly without adding those controls. Do not enter secrets or personal customer data. No remediation tools are available. All output requires review.

Prompt injection filters are incomplete. Structured-output validation and citation membership are not semantic verification. Keep the runbook corpus trusted and review generated summaries. Configure OLLAMA_URL only to a service you control. Do not post vulnerability reports containing secrets in public issues.
